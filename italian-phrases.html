動詞フレーズ

注文したいのですがVorrei ordinare.〃 オルディナーレordinare=注文する・整える。
支払いたいのですがVorrei pagare.〃 パガーレpagare=支払う。
〜を買いたいのですがVorrei comprare.〃 コンプラーレcomprare=買う（compare と混同しないように）。
袋をもらえますか？Posso avere una busta?ポッソ アヴェーレ ウナ ブスタposso=できますか / avere=持つ・もらう / una=一つの / busta=袋・封筒。イタリアはレジ袋有料が多い。
このお皿（料理）をくださいVorrei questo piatto.〃 クエスト ピアットquesto=この / piatto=お皿・料理。メニューを指差しながら使える。
文法：Posso = potere（できる）の一人称。Posso + 動詞の原形で許可を求める。

写真を撮ってもいいですか？Posso fare una foto?ポッソ ファーレ ウナ フォトfare=する・作る / una=一つの / foto=写真。バチカン・教会内は撮影禁止エリア多数。

このお皿（料理）を注文できますか？Posso ordinare questo piatto?ポッソ オルディナーレ クエスト ピアットordinare=注文する / questo=この / piatto=料理・お皿。メニュー指差しで使える。

相手にお願いする

値段を聞く

いくらですか？（一品）Quant'è?クアンテ？quanto=どのくらい + è=〜です の短縮形。
いくらですか？（1点の商品）Quanto costa?クアント コスタquanto=いくら / costa=かかる（costare=費用がかかる）。
いくらですか？（複数の商品）Quanto costano?クアント コスタノ複数になると costano に変化。商品が複数なら使い分けを。

お会計

お会計をお願いしますIl conto, per favore.イル コント ペル ファヴォーレil=定冠詞 / conto=勘定・計算書。自分から声をかけないと会計が来ない。
合計はいくらですか？Quant'è il totale?クアンテ イル トターレtotale=合計・トータル。
coperto（コペルト）＝席料・パン代。着席で€1〜3が自動加算されることが多い。チップは義務なし。

場所を聞く

もっとゆっくり話してもらえますか？Può parlare più lentamente?プオ パルラーレ ピュ レンタメンテpuò=〜できますか（敬語）/ parlare=話す / più=もっと / lentamente=ゆっくり（lento=遅い の副詞形）。

緊急・トラブル

迷子になりましたMi sono perso/a.ミ ソノ ペルソ/ペルサmi sono=私は〜した / perso=失った・迷った（perdere の過去分詞）。男性：perso / 女性：persa。
助けて！Aiuto!アイウートaiutare=助ける から。緊急時に叫ぶ。
泥棒！Al ladro!アル ラードロal=〜に向けて / ladro=泥棒。スリ多発地帯で念のため。
警察を呼んでください！Chiami la polizia!キアーミ ラ ポリツィアchiami=呼んでください（chiamare の敬語命令形）/ polizia=警察。緊急番号：警察112 / 救急118。
使い方：疑問詞 + 名詞/動詞でフレーズが作れる。指差しと組み合わせると更に便利。

Cosa — 何

これは何ですか？Cosa è questo?コーザ エ クエストcosa=何 / è=〜です / questo=これ。メニュー・展示物など何でも使える万能フレーズ。
何がおすすめですか？Cosa mi consiglia?コーザ ミ コンシーリャcosa=何 / mi=私に / consiglia=おすすめする（consigliare の三人称）。
何が起きているんですか？Cosa succede?コーザ スッチェーデcosa=何 / succede=起きる（succedere の三人称）。トラブル時・行列の理由を聞くときに。

チケットはどこで買えますか？Dove si compra il biglietto?ドーヴェ シ コンプラ イル ビリエットdove=どこ / si compra=買われる（受動的表現）/ biglietto=チケット。
タクシーはどこで見つかりますか？Dove posso trovare un taxi?ドーヴェ ポッソ トロヴァーレ ウン タクシdove=どこ / posso=できる / trovare=見つける / taxi=タクシー。

Come — どうやって・どんな

これは何という名前ですか？Come si chiama questo?コーメ シ キアーマ クエストcome=どのように / si chiama=〜と呼ばれる / questo=これ。料理・場所・商品名を聞くときに。

徒歩何分ですか？Quanti minuti a piedi?クアンティ ミヌーティ ア ピエーディquanti=いくつの（複数）/ minuti=分 / a piedi=徒歩で（piedi=足 の複数形）。
